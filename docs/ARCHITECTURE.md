# Architecture

## Components

| Layer | Path | Responsibility |
|---|---|---|
| Web UI | `frontend/` | Vanilla ES-module single-page app, served by FastAPI at `/`. No build step. Hand-written SVG charts. Google Maps is loaded on demand. |
| API | `backend/app/api/` | FastAPI routers: `operations.py` (fleet, simulator, tickets, priority), `analysis.py` (experiments, investment, public stations), `integrations.py`, `validation.py`, `meta.py` (config, health, reports). Pydantic v2 request validation; 404/409/422/502 with readable `detail`. |
| Core logic | `backend/app/core/` | Pure, unit-tested modules with no database access: `priority.py`, `policy_sim.py`, `finance.py`, `stats.py`, `catalog.py`. |
| Live simulator | `backend/app/simulator/engine.py` | Seeded step function. A background asyncio loop in `main.py` calls it every `SIM_TICK_MS` while running. |
| Services | `backend/app/services/` | `events.py` (the only code that changes charger status; validates transitions), `tickets.py` (workflow, metrics), `priority_service.py` (builds engine inputs from DB state), `validation.py`, `reports.py`, `seed.py`, `settings_store.py`. |
| Integrations | `backend/app/integrations/` | `schema.py` (normalised `ExternalEvent`), `ingest.py` (dedupe, auto-registration, per-event savepoints), `operator_api.py`, `csv_import.py`, `ocpp_central.py`, `open_charge_map.py`, `base.py` (connector interface, health, redaction). |
| Persistence | SQLite via SQLAlchemy 2.0 | Tables created on start-up (`create_schema`). Check constraints on `source` and statuses; a partial unique index enforces one unresolved ticket per charger and fault category. |

## Data flow

```
Simulator step ─┐
CSV import ─────┤                         ┌──> tickets (dedupe, workflow, history)
Operator API ───┼──> events.record_event ─┤
OCPP 1.6J ──────┘    (validate transition,│──> charger status
                      store provenance)   └──> event log
                                   │
             priority_service ─────┴──> core.priority.compute/rank ──> API ──> UI, exports

Experiments:  core.policy_sim.generate_trace(seed) ──> simulate(fifo) / simulate(priority)
              ──> metrics ──> stats.paired_summary ──> ExperimentRun (stored) ──> UI, CSV
Investment:   core.finance.evaluate(inputs) ──> UI, saved sites, comparison, validation
```

## Clocks

Simulated records use the **simulation clock** (`SimState.sim_time`, starting 23 Oct 2026 08:00 IST). Real and imported data use the wall clock. Ages, MTTA and MTTR are always computed within one clock.

## Determinism

- Live simulator: step *k* uses `random.Random(f"{seed}:{k}")`, and chargers are processed in id order. With the same seed and parameters and no manual actions, every run produces identical events (tested).
- Experiments: one trace per seed, replayed under both policies. The config hash covers every parameter, so stored results are never reused for a different configuration.

## Provenance labels

| `source` | UI label | Meaning |
|---|---|---|
| `simulation` | SIMULATED | Generated by ChargeSight |
| `operator_api` | LIVE | Received from an authorised operator API |
| `ocpp` | LIVE | Received over a real OCPP 1.6J WebSocket |
| `operator_import` | IMPORTED | Loaded from an authorised file |

Model outputs are labelled ESTIMATED, inputs ASSUMPTION, and unvalidated estimates NOT YET VALIDATED.
